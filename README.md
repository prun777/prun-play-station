# PRUN PLAY STATION · 1:24 微缩场景

一个完全离线的 Three.js 低多边形微缩场景：**“Prun 游戏店 / PRUN PLAY STATION · GAMES & SERVICING”**。
深色展示界面、46 个独立可点击对象、四季昼夜、雨雪雷暴、可收回的巨物事件，适合录屏与短片。

## 预览

`previews/` 里有 6 张成片截图：春日白天、春夜、雨夜、巨物事件、冬日、电影模式（干净画面）。

## 运行

**直接双击 `index.html`** 即可（`file://` 打开，无需服务器、无需联网、无 CDN / 外部图片 / 音频）。
所有依赖只有同目录下的 `vendor/three.min.js`（three.js r159，MIT，许可证见 `vendor/THREE-LICENSE.txt`）。

推荐 Chrome / Edge / Safari 最新版；需要 WebGL2。录屏建议 1600×900 或 1920×1080。

## 操作

| 操作 | 说明 |
|---|---|
| 拖动 / 滚轮 | 环绕旋转 / 缩放 |
| 点击对象 | 打开详情卡；维修设备（检修台、检测仪器、拆机台）会同时打开诊断 HUD |
| 悬停 | 青色描边高亮 |
| 视角复位 | 平滑回到初始机位；若巨物事件进行中会一并收回 |
| 自动旋转 | 缓慢环绕 |
| 电影模式 | 隐藏 UI + 上下遮幅，慢速环绕；`Esc` 或双击退出 |
| 组装动画 | 所有对象从空中依次落位 |
| 巨物来袭 | 3 秒预警后隧道亮红光、喷烟，机械头颅与肩甲驶出；再次点击平滑收回 |
| 全屏 | 右下角按钮 |

右侧面板：

- **SEASON & TIME**：春夏秋冬；拖动时刻滑杆；`自动循环 · 30 秒 / 天`。
- **WEATHER**：晴天 / 下雨 / 雷阵雨 / 薄雾；雨量强度滑杆（路面湿润、积水霓虹倒影、倾斜雨丝、探照灯柱）。

- 35.8 × 26.8 的地质切块底座：海岸、沙滩、棕榈与阔叶树、公路、斑马线、前场停车、路边休息区（木平台、长椅、圆桌、自动售货机）。
- 左翼两层玻璃游戏店：电玩服务区（主机检修台、检测仪器、手柄支架、配件货架、游戏陈列柜、工具墙、拆机维修设备、体验桌椅、收银台、试玩电视墙）。
- 右翼加宽双层玻璃仓库：工业货架、设备纸箱、配件抽屉、待检修区、工具车，以及搬运工、盘点员、检修工、带火花与局部橙光的电焊工。
- 二楼：老板办公室（办公桌、蓝光显示器、老板椅、客椅、文件柜、大型绿植、汇报 NPC）与员工休息区（长沙发、茶几与杯子、饮水机、壁挂电视、复古街机、坐姿 NPC）；暖色工业吊灯与柔和光锥。

- 巨物事件：隧道红光 + 烟雾 + 机械头颅/肩甲、红色 SpotLight 双眼、缓慢扫视；车辆冻结转向双闪、NPC 四散、行人小狗沿人行道往返；收回时全部平滑复位。

## 截图 / 录屏参数（确定性时间冻结）

页面支持 URL 参数，用于固定一个时刻渲染（便于截图和录制）：

```
index.html?shot=1&t=8&season=winter&hour=21&weather=rain&rain=0.8
index.html?shot=1&t=18&alert=1&hour=21
index.html?cinema=1&season=autumn&hour=16
```

- `shot=1`：冻结模式，按 `t` 秒预演后只渲染一帧（不启动动画循环）。
- `t`：预演秒数；`season`、`hour`、`weather`、`rain`：场景状态。
- `alert=1`：触发巨物事件（`eventAt` 可指定预警已过去的秒数）。
- `theta` / `phi` / `radius` / `tx` / `ty` / `tz`：指定机位与注视点。
- `cinema=1`：直接进入电影模式（隐藏 UI），适合干净录屏。

## 实现说明

- 渲染：`WebGLRenderer` + ACES 色调映射 + PCF 软阴影；物理光照单位。
- 玻璃：高透明低反射（opacity ≈ 0.07，clearcoat 很低），只留框料高光，不产生彩色光晕。
- 粒子预算：花瓣 140、落叶 96、雪 720、雨 1100 条线、火花 150、烟 90、萤火 36；全部 CPU 更新、单缓冲区，避免每帧分配。
- 动画统一由 `main.js` 的 `animate()` 驱动：`updateTweens → updateCamera → updateSky → updaters`。
- 招牌使用 CanvasTexture 静态贴图，不随机闪烁；所有摆件都落在支撑面上，并加了接触阴影。
- 为方便点击室内物件：玻璃幕墙的竖框不参与拾取，幕墙在后墙有一块隐形拾取代理；三台维修设备各有隐形拾取体，点击后打开诊断 HUD。
- 对象注册与拾取、相机、材质缓存见 `js/core.js`；场景分块在 `world / building / actors / effects / kaiju / ui`。
